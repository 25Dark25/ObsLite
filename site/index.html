Why it's light

Light by design, not by settings.

You can spend an evening tuning OBS Studio so an old laptop keeps up. Or you can use a recorder built from the start to stay out of the way of the game or app you are recording.

01

Your GPU does the heavy lifting

Video is encoded to H.264 by the graphics card's hardware encoder: NVIDIA NVENC, Intel Quick Sync, AMD AMF, or VA-API on Linux. On Windows, and with VA-API on Linux, each frame stays on the GPU from capture to encoder.

02

No work when nothing changes

On Windows, the screen is captured only when the image changes; Obs Lite repeats the last frame to keep a constant frame rate, so your video editor gets clean 30 or 60 fps.

03

No browser inside

Obs Lite is a native program written in Rust, with no bundled browser engine: one ~7 MB .exe on Windows, a ~4 MB Flatpak on Linux.

04

It does one thing: record

No streaming, scenes or plugins to load. What it leaves out is what keeps it small, and what makes it simple to use.

Choose Obs Lite if you

  • want to record gameplay, tutorials, classes or meetings,
  • have an older PC or a low-end laptop and every bit of CPU and memory counts,
  • want something that works right after installing, with no settings to tune.

Choose OBS Studio if you

  • stream to Twitch, YouTube or Kick,
  • build scenes with several sources, filters and transitions,
  • need plugins or other formats and codecs.

Features

Everything you need to record. Nothing you don't.

The recording tools people use every day in OBS Studio, with OBS's own wording, so you find everything where you expect it.

Display · Window · Region

Screen or window

Record a whole display or a single window, with or without the cursor, or drag a rectangle on the preview to record only part of it.

H.264 + AAC · MP4

Plays everywhere

MP4 files at a constant 30 or 60 fps that open in every player and video editor, scaled on the GPU to 1440p, 1080p or 720p if you like.

Desktop · Mic/Aux

Desktop audio and mic

Mixed together, each with its own meter, volume and mute button. Mute works in the middle of a recording.

Windows

One app's audio

Record a game's sound without your Discord call: Application Audio Capture gives one program its own mixer channel.

5–600 s

Replay buffer

Keeps the last seconds in memory, already encoded. Press Save Replay to keep a moment that already happened.

Crash-safe MP4

Recordings survive a crash

If the PC crashes or loses power, the recording is kept, and turned into a regular MP4 the next time Obs Lite starts.

Picture-in-picture

Webcam overlay

Show your webcam on the recording. Drag it on the preview to move it, or its corner to resize it.

RNNoise

Noise suppression

Removes fan hum and keyboard clatter from the microphone, with the same filter OBS Studio offers.

Ctrl+Alt+R

Global hotkeys

Start, stop, pause, save a replay, take a screenshot or mute the mic from inside any game or app.

No gaps

Pause and resume

Paused time never reaches the file, in video or in audio.

Windows

Hidden from capture

The Obs Lite window never shows up in your recordings or in its own preview.

Get started

Recording in under a minute.

No account, no setup wizard, no settings to tune first.

  1. Install

    Run the installer: no administrator rights needed. Or unzip the portable version anywhere. On Linux, install the Flatpak.

  2. Record

    Press Start Recording, or Ctrl+Alt+R from anywhere. It records your main display and desktop audio at 60 fps.

  3. Done

    Your MP4 is in the Videos folder, named after the time it started. File › Show Recordings opens it.

Windows may show “Windows protected your PC” the first time. Obs Lite is signed with OpenPGP instead of a paid Windows code-signing certificate, so SmartScreen does not recognise it yet. Click More info, then Run anyway.

Every file has a PGP signature and a GitHub build attestation, so you can check it is genuine. The source code is public on GitHub.

Windows

  • Windows 11, 64-bit. Windows 10 has not been tested yet.
  • A GPU with a working driver: NVIDIA, Intel or AMD. Without a hardware encoder, Windows' software encoder takes over (more CPU).

Linux

  • Flatpak and PipeWire, on x86_64.
  • A desktop with the screen-sharing portal: GNOME, KDE Plasma and most Wayland desktops. Works on Wayland and X11.

FAQ

Questions, answered.

What is the best screen recorder for a low-end PC?

One that hands the encoding to the graphics card and carries nothing you don't use. Obs Lite was made for exactly that: it records with the GPU's hardware encoder (NVENC, Quick Sync, AMF or VA-API), is a {{MSI_SIZE}} download, and uses about 100 MB of memory with the preview running. It needs a GPU or integrated graphics with a working driver; most Intel, AMD and NVIDIA graphics from the last decade have a hardware H.264 encoder.

Is Obs Lite a lighter alternative to OBS Studio?

For recording, yes. Obs Lite has the same layout as OBS Studio (preview, Sources, Audio Mixer, Controls) and uses OBS's wording, but it only records: no streaming, scenes or plugins. In exchange, its Flatpak is 3.7 MB against 225 MB, and it uses less memory. If you stream or build scenes, OBS Studio is the right tool.

Is Obs Lite made by the OBS Project?

No. Obs Lite is an independent project, written from scratch in Rust. It contains no OBS code and is not affiliated with, endorsed by or sponsored by the OBS Project. It follows OBS Studio's interface so that OBS users feel at home.

Is it really free?

Yes. Obs Lite is free and open source under the MIT license: no ads, no account, no watermark and no time limit on recordings.

Can I record a game without recording my Discord call?

Yes, on Windows. Add an Application Audio Capture source for the game: its sound gets its own channel in the mixer, and desktop audio leaves it out. Mute desktop audio, and the game is recorded without the call.

Why does Windows say “Windows protected your PC”?

Windows SmartScreen warns about programs that are not signed with a paid Windows code-signing certificate. Obs Lite is signed with OpenPGP instead, and every file comes with a GitHub build attestation that shows which commit it was built from. Click More info, then Run anyway.

What happens if my PC crashes while recording?

The recording is kept. Obs Lite writes the MP4 in small fragments, so after a crash or a power cut the file has everything but the last fraction of a second, and the next time Obs Lite starts it turns it into a regular MP4.

Where are my recordings saved?

In your Videos folder, as MP4 files named after the time the recording started (for example 2026-10-16 13-45-02.mp4). You can change the folder in Settings › Output.

Does Obs Lite collect any data?

No. On Windows it only asks GitHub at start-up whether there is a newer version, and you can turn that off in Settings › General. The Linux Flatpak has no network access at all.

Does it work on Windows 10?

It has not been tested there yet. Obs Lite is built and tested on Windows 11; if you try it on Windows 10, a report on GitHub is very welcome.
